# Real-Time Color Detection

Identifies multiple colors in real time using OpenCV + PyQt5.

## How to Run
1. Install dependencies:
```
    pip install -r requirements.txt
```
2. Launch:
```
    python color_detection_app.py
```
3. Point your webcam at colored objects. Bounding boxes/labels appear for each detected color.
